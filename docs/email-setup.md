# Настройка отправки почты (SMTP)

Письма нужны для двух вещей: **подтверждение почты** после регистрации и
**восстановление пароля** («Забыли пароль?»).

Пока SMTP не настроен, сайт работает в **dev-режиме**: письма никуда не
отправляются, а сохраняются файлами в папку `var/outbox/` бэкенда — их можно
открыть в браузере и нажать на ссылку внутри. Для локальной разработки этого
достаточно. Для настоящего сайта нужен SMTP — 10–15 минут по инструкции ниже.

## Какие переменные нужны

В файле `.env` бэкенда (там же, где `PORT` и пароль базы) нужно раскомментировать
и заполнить пять строк:

```
SMTP_HOST=...   адрес почтового сервера
SMTP_PORT=...   порт: 465 (SSL) или 587 (STARTTLS)
SMTP_USER=...   логин
SMTP_PASS=...   пароль приложения или API-ключ (НЕ обычный пароль от почты)
MAIL_FROM=...   от кого письмо, например: DnD-Hub <адрес@…>
```

После изменения `.env` перезапустить бэкенд (`npm run dev` перезапустится сам,
если уже запущен через nodemon — достаточно сохранить файл; иначе остановить и
запустить заново).

## Вариант 1 — Яндекс.Почта (проще всего, бесплатно)

Подойдёт обычный ящик на Яндексе. Письма будут уходить с вашего адреса.

1. Зайдите в почту на [mail.yandex.ru](https://mail.yandex.ru) под ящиком,
   с которого сайт будет слать письма (можно завести отдельный, например
   `dndhub.notify@yandex.ru`).
2. Разрешите доступ по SMTP: откройте **Настройки (шестерёнка) → «Все настройки» →
   «Почтовые программы»** и поставьте галочку **«С сервера imap.yandex.ru по
   протоколу IMAP»** и ниже — **«Пароли приложений и OAuth-токены»** (если такая
   галочка есть).
3. Создайте **пароль приложения**: [id.yandex.ru/security](https://id.yandex.ru/security)
   → «Пароли приложений» → «Создать новый пароль» → тип **«Почта»**, название
   любое (например «DnD-Hub»). Яндекс покажет пароль **один раз** — скопируйте его.
4. Впишите в `.env`:

   ```
   SMTP_HOST=smtp.yandex.ru
   SMTP_PORT=465
   SMTP_USER=ваш_ящик@yandex.ru
   SMTP_PASS=пароль_приложения_из_шага_3
   MAIL_FROM=DnD-Hub <ваш_ящик@yandex.ru>
   ```

   ⚠️ У Яндекса адрес в `MAIL_FROM` обязан совпадать с `SMTP_USER`, иначе письма
   не уйдут.

## Вариант 2 — Resend (сервис рассылок, до 100 писем в день бесплатно)

Подойдёт, когда появится свой домен: письма будут уходить с адреса вида
`no-reply@ваш-домен`.

1. Зарегистрируйтесь на [resend.com](https://resend.com) (можно через Google).
2. В панели: **Domains → Add Domain** → введите свой домен → Resend покажет
   DNS-записи, их нужно добавить у регистратора домена (там же, где покупали
   домен). Подождите, пока статус станет **Verified**.
3. **API Keys → Create API Key** → скопируйте ключ (показывается один раз).
4. Впишите в `.env`:

   ```
   SMTP_HOST=smtp.resend.com
   SMTP_PORT=465
   SMTP_USER=resend
   SMTP_PASS=ключ_из_шага_3
   MAIL_FROM=DnD-Hub <no-reply@ваш-домен>
   ```

Без своего домена Resend позволяет слать только на вашу собственную почту —
для проверки хватит, для настоящих пользователей нужен домен.

## Как проверить, что заработало

1. Перезапустите бэкенд после правки `.env`.
2. Откройте сайт и зарегистрируйте нового тестового пользователя на **свою**
   реальную почту.
3. В почту должно прийти письмо «Подтвердите почту — DnD-Hub» (проверьте папку
   «Спам»). Кнопка в письме должна открывать сайт и показывать «Почта
   подтверждена».
4. Если письмо не пришло — посмотрите лог бэкенда (окно, где запущен
   `npm run dev`): строки, начинающиеся с `[mail]`, покажут, ушло письмо через
   SMTP или упало с ошибкой.

Пока SMTP не настроен, в логе будет строка `[mail] SMTP not configured…`, а
письмо появится файлом в `var/outbox/` — это нормальный dev-режим, ошибкой не
является.

## Частые проблемы

| Симптом | Причина |
|---|---|
| `Invalid login / 535` | В `SMTP_PASS` обычный пароль от почты вместо пароля приложения / API-ключа |
| Письма уходят, но не доходят | Проверить «Спам»; для Resend — домен не Verified |
| `Sender address rejected` | `MAIL_FROM` не совпадает с `SMTP_USER` (правило Яндекса) |
| Ссылка в письме ведёт не туда | Проверить `FRONTEND_URL` в `.env` — это адрес сайта, который попадает в ссылки |
